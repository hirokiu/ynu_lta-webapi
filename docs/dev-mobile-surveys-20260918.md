# devモバイル回答接続とiOSデザイン第1段階

## 現在地
保全、新サーバー準備、proto管理画面公開まで完了。共同研究者確認とdevアプリ検証を並行。最終移行・旧サーバー解約は未実施。

## 接続と検証
- GET /api/meでFirebase UIDをサーバー既存マッピングに照合しuserIdだけ返す。メール文字列からuserIdを生成しない。未認証は401、キャッシュ禁止。
- dev APIは既存dev版2be1cdeから分岐した0c884d7を使用。image kirokun-api:dev-mobile-0c884d7。Webは従来イメージの同一内容を同タグに再タグ付け。proto/旧サーバーのコード、通知設定、データは変更しない。
- dev DBをバックアップ後、APIだけ更新。通知・配信準備はfalseを維持。
- iOS devのSurvey一覧から既存の回答画面に接続。回答可・回答済み・期限終了と期限日時を表示。
- 送信のHTTP結果を確認し、成功時だけ回答画面を閉じる。失敗時は入力を画面内に保持。アプリ終了後の下書き永続化は未実装。
- UI操作でテスト02に「動作確認」を入力。Macのdev専用SSHポート転送を一時停止して失敗表示と入力保持を確認し、復旧後の再送信を実施。DBのdataset.answers[0].stringValueが「動作確認」と一致し、一覧も回答済みになることを確認。
- テスト01は空文字の保存経路確認。現在の自由記述フォームは空文字を許容する。必須回答仕様は今回変更していない。
- テスト03は上松さんの確認用に未回答のまま残す。全て架空のテストデータ。
- /api/me未認証401、APIビルド、既存UID/クエリ検証を通過。

## iOSデザイン
- アイコンの主要色は#FF5857。操作用の文字・線はコントラストを確保した濃淡バリエーション。
- ネイティブナビゲーションとiOS26以降の補助操作にLiquid Glassボタンを採用。主要ボタンはコーラルの塗りと濃色文字で可読性を確保。透明度を下げる設定では補助操作も通常ボタンに切り替え、旧OSにもフォールバック。
- 一覧は標準のグループ化されたセル、期限と回答状態を文字でも表示。主要操作はコーラル、回答欄は不透明な背景。開始・前へ・次へ・送信の位置は維持。
- devの設問アイコンをSF Symbolsへ統一。自由記述欄はDynamic Typeとアクセシビリティラベルを追加。
- 設問形式・分岐仕様の追加、大幅なフォームレイアウト変更、フォーム全体のダークモードは次段階。現フォームはライト表示を維持。
- このUI変更はdevビルド限定。proto/ストア版へはまだ展開しない。

## 残る確認
Androidの実Googleログイン、UID回答画面接続、通知・実機・全設問形式・大きい文字での包括的検証は別段階。今回の実操作はiOSシミュレーターの自由記述1設問。研究データの移行完了や旧サーバー解約の判定には使用しない。
