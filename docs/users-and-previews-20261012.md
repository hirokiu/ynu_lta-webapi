# Usersのユーザー名表示・一覧プレビュー改善

## 仕様

- 管理者用のUsers一覧・検索・詳細APIに `username` を追加。LoginAccountをACCOUNT_SCOPEとuserIdで参照し、返す認証情報はユーザー名だけ。パスワードなどは返さない。
- データベース内のuserId、UID、回答・配信との参照関係は変更しない。
- 従来アカウントで認証用の別レコードがない場合は既存のuserIdをユーザー名として扱う。ランダム形式の内部IDに対応するアカウントがなければ「ユーザー名未設定」を表示。
- Users一覧とプレビューにはユーザー名を表示。詳細画面にユーザー名と「内部ID（userId）」を表示する。
- 検索はユーザー名と従来IDの部分一致。正規表現として解釈せず文字列検索する。
- Users・Surveys・Groupsの固定幅一覧を画面幅に収まる2列に変更。右側プレビューはsticky、画面高を超える内容は枠内スクロール。767px以下では下部に最大40%の高さで表示。

## 検証

APIビルド、Webビルド、隔離MongoDB4.2.24によるuser-names.integration.test.jsが成功。確認項目は一覧・検索・詳細、内部ID維持、従来ユーザー名、環境分離、秘密フィールド非公開、管理者権限。

APIソース33ed0da、Web92d01e7。イメージはkirokun-api/web:proto-users-20261012。
