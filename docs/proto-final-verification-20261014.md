# Proto新規参加者の最終確認（2026-10-14）

検証専用のiOS・Android各1名を招待・有効化し、通常のProtoアプリでログイン。端末通知先の登録と通常の配信処理での通知送信を確認した。検証Survey自体はDBに専用データとして作成しており、管理画面からの新規Survey作成をこの試験で保証するものではない。

iOSは通知から回答送信成功。Android版6では通知タップ後に白画面となり、版7で起動時の画面遷移を修正。OPPOへ上書き後、通知の再送1通から回答送信まで本人が確認した。

稼働中Protoの出力実装を検証Surveyだけに適用し、保存済み回答2件、JSON2件、CSV2件を確認。CSVとJSONの各値は一致。JSON292バイト、CSV213バイト。全体の孤立した回答レコード数は0。回答本文・パスワード・通知トークンは記録しない。

この確認はサーバーの出力処理を直接呼び出したものであり、ブラウザーからの認証付きダウンロード操作は未確認。単発配信の期限保存修正はローカルコミットc5a0c53にあり、稼働環境への反映・確認は別途必要。

配布候補はiOS 2.0.0(2026101202)、Android 2.0.0(7)。ストアへの提出・一般公開は未実施。Google Playアカウントの登録状況、署名鍵の安全な別保管、審査用情報・アカウントの確認が残る。
